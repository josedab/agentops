# Contributing

Welcome! AgentOps is open source and we appreciate contributions.

## Quick Links

- [Development Setup](/docs/contributing/development-setup)
- [Code of Conduct](/docs/contributing/code-of-conduct)
- [GitHub Repository](https://github.com/josedab/agentops)

## Ways to Contribute

- **Bug reports** - Open an issue
- **Feature requests** - Start a discussion
- **Documentation** - Fix typos, add examples
- **Code** - Fix bugs, add features

## Getting Started

1. Fork the repository
2. Clone your fork
3. Follow the [development setup](/docs/contributing/development-setup)
4. Create a branch for your changes
5. Make your changes
6. Run tests: `pnpm test`
7. Submit a pull request

## Pull Request Guidelines

- [ ] Tests pass (`pnpm test`)
- [ ] Linting passes (`pnpm lint`)
- [ ] Build succeeds (`pnpm build`)
- [ ] Documentation updated if needed
- [ ] Conventional commit messages used
