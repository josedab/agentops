## Overview

Cost tracking gives you complete visibility into your AI spending, helping you understand where money goes and how to optimize.

## Automatic Cost Calculation

AgentOps automatically calculates costs based on:

- **Model** - Different pricing per model
- **Tokens** - Input and output token counts
- **Provider** - OpenAI, Anthropic, etc.

```typescript
const response = await openai.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: 'Hello!' }],
});

// AgentOps automatically tracks:
// - Prompt tokens: 10
// - Completion tokens: 15
// - Cost: $0.000125
```

## Cost Attribution

### By Feature

Track costs per feature or flow:

```typescript
const client = agentops.wrap(new OpenAI(), {
  featureId: 'code-review',
});

// All costs attributed to 'code-review'
```

Dashboard shows cost breakdown by feature:
- Chat: $45.23 (35%)
- Code Review: $32.10 (25%)
- Summarization: $25.67 (20%)

### By User

Track costs per user:

```typescript
const client = agentops.wrap(new OpenAI(), {
  userId: 'user_123',
});

// Costs attributed to user_123
```

### By Model

See which models drive costs:
- gpt-4o: $85.50 (65%)
- claude-3-5-sonnet: $35.20 (27%)
- gpt-4o-mini: $10.30 (8%)

## Cost Budgets

Set spending limits:

```typescript
// In dashboard settings
{
  dailyBudget: 100,      // $100/day
  monthlyBudget: 2500,   // $2500/month
  alertThreshold: 80,    // Alert at 80%
}
```

## Cost Alerts

Get notified when spending exceeds thresholds:

- **Daily budget** - Alert when approaching limit
- **Unusual spike** - Detect anomalies
- **Per-user limit** - Cap individual usage


- Time (hourly, daily, weekly)
- Feature
- User
- Model
- Environment
