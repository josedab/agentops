## Overview

AgentOps dashboards provide real-time visibility into your AI agent performance, costs, and quality metrics.

## Overview Dashboard

The main dashboard shows key metrics at a glance:

### Key Metrics
- **Sessions** - Total sessions in time period
- **Events** - Total events tracked
- **Total Cost** - AI spending
- **Error Rate** - Percentage of failed sessions

### Charts
- **Sessions over time** - Line chart of session volume
- **Cost over time** - Stacked area chart by model
- **Latency distribution** - Histogram of response times
- **Model usage** - Pie chart of model distribution

### Recent Sessions
Quick view of latest sessions with status and cost.

## Sessions View

### Session List
Browse all sessions with filters:
- Time range
- Status (active, completed, error)
- User ID
- Feature ID
- Tags
- Model

### Session Detail
Drill into individual sessions:

1. **Header** - Duration, cost, status, user
2. **Timeline** - Expandable list of events
3. **Event Detail** - Click to see full content
4. **Metrics** - Token usage, latency by step

## Cost Analytics

### Cost Overview
- Current period spending
- Budget utilization
- Projected monthly cost

### Cost Breakdown
Group costs by:
- **Model** - Which models cost most
- **Feature** - Cost per product feature
- **User** - Cost per user
- **Time** - Daily/weekly trends

### Cost Trends
- Compare to previous periods
- Identify anomalies
- Track optimization impact
